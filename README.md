# 🎈 لعبة الحروف - Letters Game

لعبة تعليمية للأطفال لتعلّم الحروف العربية والإنجليزية: تعلّم، تدرّب على النطق بالمايكروفون، تدريبات، واختبار بالنجوم.

An educational game for kids to learn Arabic & English letters: learn, practice pronunciation with the mic, exercises, and a star quiz.

## التشغيل / Run

ملف واحد فقط: `index.html`. افتحه في المتصفح مباشرة، أو انشره على GitHub Pages.

## النشر على GitHub Pages

1. ارفع `index.html` و `README.md` إلى مستودع جديد.
2. من **Settings → Pages** اختر Branch: `main` و Folder: `/ (root)` ثم Save.
3. سيظهر الرابط: `https://USERNAME.github.io/REPO/`

## ملاحظات

- النطق (TTS) يعمل في أغلب المتصفحات.
- التعرف على الصوت يتطلب Chrome أو Edge، ويحتاج اتصال إنترنت وإذن المايكروفون.
